The azure devops api can be used with PAT in environment variable "AZURE_DEVOPS_PAT" and the base address of the azure devops instance is "https://dev.azure.com/Dataglide"

If you choose to, or are asked to reply to a ticket, prefix the message with "Agent Response: ".
